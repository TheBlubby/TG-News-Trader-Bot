# TG News Trader Bot - Local Setup Guide

## Запуск 0ms HFT-бота локально

Для торговли на новостях каждая миллисекунда важна. Серверные решения вроде Vercel медленные, поскольку используют HTTP-пуллинг. Этот бот использует библиотеку **MTProto (GramJS)** для прямого подключения к серверам Telegram по сокетам, что дает задержку в 0 миллисекунд — бот реагирует в тот же момент, когда выходит пост.

### Шаг 1: Скачайте проект
1. В правом верхнем углу интерфейса настройки нажмите **Settings ⚙️ -> Export -> Download ZIP**.
2. Распакуйте архив на вашем компьютере.
3. Убедитесь, что установлен **Node.js** (скачать с [nodejs.org](https://nodejs.org/)).

### Шаг 2: Установка зависимостей
Откройте терминал в папке с распакованным проектом и выполните:
```bash
npm install
```

### Шаг 3: Получение Telegram Session String
Чтобы бот мог читать каналы от вашего имени (или имени вашего тех-аккаунта), ему нужна авторизация из терминала.
1. Зарегистрируйте приложение на `my.telegram.org` и скопируйте `api_id` и `api_hash`.
2. В терминале выполните:
```bash
npm run generate-session
```
3. Введите ваш `api_id`, `api_hash`, номер телефона и код из Telegram.
*(Если код не приходит, используйте `npm run generate-session-qr` для входа через ссылку по QR)*
4. Скопируйте сгенерированную длинную строку сессии `Session String`.

### Шаг 4: Запуск бота
Выполните:
```bash
npm run dev
```
1. Откройте **http://localhost:3000**
2. В настройках **Platform Integration** введите данные вашего MEXC и вставьте полученные `API_ID`, `API_HASH` и `Session String`.
3. Сохраните конфигурацию и на главной панели нажмите **Start Bot**! Бот подключится и будет слушать выбранный канал.

## Запуск на Сервере (VPS) для работы 24/7

Чтобы бот работал круглосуточно, его нужно разместить на виртуальном сервере (VPS) и использовать менеджер процессов (например, **PM2**).

### 1. Какой сервер выбрать? Возле биржи (Очень важно!)
Для **HFT (высокочастотной)** торговли на новостях физическое расстояние от вашего сервера до серверов биржи играет огромную роль. 
* Сервера биржи **MEXC** расположены в Азии (в основном AWS Токио и Сингапур).
* Если вы купите сервер в Европе (Германия, Нидерланды) — пинг до биржи будет 150-250 миллисекунд.
* **Правильный выбор:** Покупайте VPS с локацией в **Японии (Токио)** или **Сингапуре** (например, у провайдеров Vultr, DigitalOcean, AWS EC2, Hetzner - если есть азиатские локации).
* **Характеристики:** Хватит самой дешевой машины (1 vCPU, 1-2 ГБ ОЗУ) на **Ubuntu 22.04** или **24.04**.

### 2. Подготовка сервера и перенос кода
1. Подключитесь к вашему новому серверу по SSH (используя Termius, PuTTY или терминал macOS/Linux).
2. Обновите пакеты и установите Node.js:
```bash
sudo apt update && sudo apt install -y curl
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs git
```
3. Перенесите код бота на сервер (лучший способ — загрузить код на приватный репозиторий GitHub и сделать `git clone` на сервере, либо перенести всю папку через SFTP программу: Termius / FileZilla).

### 3. Установка, сборка и запуск 24/7 через PM2
Откройте папку с проектом на сервере и выполните:
```bash
# 1. Установите зависимости
npm install

# 2. Соберите проект (скомпилируйте TypeScript для продакшена)
npm run build

# 3. Установите менеджер PM2 глобально
sudo npm install -y -g pm2

# 4. Запустите бота 24/7
pm2 start dist/server.cjs --name "tg-bot"

# 5. Сохраните процесс, чтобы он включался автоматически после перезагрузки сервера
pm2 save
pm2 startup
```

### 4. Входим в панель управления
После запуска PM2, интерфейс бота будет доступен по адресу вашего сервера:
**http://<IP_АДРЕС_ВАШЕГО_СЕРВЕРА>:3000**
Заходите туда, прописываете ключи (MEXC, Telegram Session) и нажимаете кнопку запуска!
